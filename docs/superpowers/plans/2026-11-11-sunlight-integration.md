# 正式光照表现接入

按已审核样片接入正式 BoardView。太阳图标放在棋盘的入光侧；取消方向箭头与标题旁图标。场景外光晕降饱和、减弱，并把中心移到视口外。

1. 保持 Core 的两格太阳投影、四向灯射线、镜子和门规则。用共享格子数据驱动灯光束，用墙/物体的几何投影绘制渐变阴影。
2. 阴影合并取较暗值，避免重叠加黑；移动投影跟随物体插值。复用材质、网格和小尺寸格子纹理，释放 BoardView 自有资源。
3. 游戏与编辑器共用渲染；编辑器视口裁剪、平移缩放、五套主题、昼夜和四向太阳一并验证。
4. 将旧编辑器样片改为正式渲染的捕获入口。运行编译、后台 Play 回归及实际相机截图，保留证据。此次不改关卡与规则，不保存无关场景。
