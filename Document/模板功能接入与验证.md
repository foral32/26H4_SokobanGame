# 模板功能接入与验证

## 通用工具与渲染
- Tools/Scene/Alt 拖轴复制可切换开关；Alt 空白处仍沿用场景导航。验证菜单会使用 Undo 栈，实际手柄命中需人工体验。
- Tools/Toolbar 沿用模板截图入口和跨机器默认目录；Cursor IDE 包固定到 manifest 中指定的提交。
- 描边沿用现有 Renderer Feature 和作者配置；算法参数与两条渲染路径说明见 Assets/Scripts/Shader/PPOutline/Post Process OutlineREADME.md。
- PostProcessManager.PlayVignettePulse 是临时反馈；重复触发和结束恢复需与常驻暗角一起检查，不需要替换全局 Volume。

- 暗角允许在 Profile 中缺省；首次请求时仅在运行时副本补齐，结束恢复原强度及覆盖状态，不修改共享 Profile 资产。

## 字体
- 中文正文选择思源黑体 SDF_4900 静态图集，已有 fallback 指向动态 SDF；未改变 TMP 全局默认字体。
- 静态图集提供常用字、ASCII 与标点；罕见字由动态字体补充，不提交试玩中增长的缓存。
