# 作品演示

## 用途与入口

以「技术策划求职 Demo」介绍作品的玩法设计、关卡工具与产品打磨。主菜单右边缘挂接手账签「作品演示！」，采用纸张衬边、酒红封面与疏缝线。首次进入主菜单 4 秒后轻摇约 0.9 秒，此后默认间隔 4 秒；间隔可在 `GameUI` 组件的 `showcaseShakeIntervalSeconds` 字段调整。悬停时展开并稳定。打开演示后永久停止提醒，按本机项目记录已查看状态，隔离验证不写入此记录。它与右下角「编辑正式关卡」的外观在未 Play 的 Scene／Game 视图也可见，功能在 Unity 编辑器 Play 中使用；正式包移除两个入口。四个主菜单项保持原位置。

## 窗口与导航

保留约四分之三屏幕的独立弹窗、压暗主菜单、游戏字体与主题色、切角细边框。顶部使用 README／关卡设计／关卡编辑器／产品打磨四个页签。

README 左侧为项目字标与 `made by vvvoidcake`，右侧介绍项目定位、基本玩法与演示用法，不播放录像。其余页面左侧为 16:9 实机录像，右侧为标题与多段说明；视频由原来的 744 × 418.5 缩为 584 × 328.5（1280 × 720 基准画布）。正文保留具体规则、设计意图和工具行为，不堆叠无关指标；下方集中翻页箭头与圆点。

- 首次进入 README。各组独立记忆页码，关闭后再开保留本次会话位置。
- 点击箭头或按左右键翻页；圆点直接跳页；点击页签或 Tab 循环切组。左右键和翻页按钮按 README、关卡设计、关卡编辑器、产品打磨连续翻阅；跨模块向右进入第一页，向左进入上一模块最后一页，整本首尾停止。直接点击页签及 Tab 仍保留各组阅读位置。README 不显示翻页控件。
- 视频静音循环，保留游戏 BGM。悬停画面显示暂停按钮，空格暂停／继续。
- 右上角叉或 Esc 关闭，返回原主菜单；F1 也可从主菜单打开。
- 开窗淡入并轻缩放，关闭快速收回。窗口打开时阻断底层菜单的鼠标及键盘输入。

## 内容与素材

正式内容位于 [Pages.json](../../Assets/DraculasBox/Showcase/Editor/Pages.json)。视频来自隔离 Play 中的真实棋盘与原生 UI，录制过程使用临时存档及复制的正式目录。观看时只播放录像，不执行其中的操作。

| 页签 | 内容 | 画面重点 |
|---|---|---|
| README | 项目与演示简介 | 项目字标、定位、阅读引导、作者署名 |
| 关卡设计 | 五页机制设计 | 躲光入棺、两格箱影、隔箱推灯、门与光路、固定镜向 |
| 关卡编辑器 | 六页制作工具 | 选择绘制、F5 往返、求解回放、草稿预设、章节编排、自定义导入与写回 |
| 产品打磨 | 三页体验细节 | 动作与死亡撤销、主题切换、章节完成与解锁 |

视频与封面集中放在 [Showcase/Editor/Clips](../../Assets/DraculasBox/Showcase/Editor/Clips/)，维护方式见同级 README。素材与演示代码都按 Editor 隔离，不进入正式包。机制介绍只覆盖当前已实现内容；难度不宣称为客观标定，高箱与时段切换不列为现成功能。

旧截图原型和独立原生预览窗口保留为设计记录，不作为当前游戏入口。原型素材见 `ReferenceStills/`；当前可体验状态与验证结果统一记录在[版本路线](../版本开发文档.md)。
