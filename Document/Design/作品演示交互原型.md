# 作品演示 · 交互原型

2026-11-11，第二稿。当前为 Unity 原生评审窗口，未接入游戏主菜单，未录制正式视频。

## 用途与入口

作品以「技术策划求职 Demo」定位呈现。让观看者先看懂玩法，再能直观看到关卡工具如何服务创作。本稿默认先打开 TD，LD 随时可切换；此顺序是本轮提案。

正式接入后只在 Unity 编辑器的 Play 中提供入口。主菜单屏幕右边缘挂一截手账索引签，露出的纸面写「点我进行／演示」，浅纸色、酒红窄边和少量装订虚线。索引签以右边缘为支点轻晃，悬停时向内伸出约 12 px 并稳定；不在画面中悬浮整张便签。四个主菜单项与右下角正式关卡入口保留位置，不自动弹出演示。

## 窗口与导航

按游戏引导弹窗组织：主菜单压暗，上方是作品名、定位和小型 TD／LD 页签；中央是演示画面，画面下方为翻页圆点和左右箭头，再下方只放两行短说明。关键机制或操作用项目现有金色强调。使用酒红主题的暗色遮罩、暖白文字、游戏图标与字体，不再使用整块浅色卡片、左文右图或常驻视频工具栏。

- 首次打开为 TD 第 1 页；两组页签分别记住阅读位置，关闭后再开保留本次会话位置。
- 点箭头或按左右键翻页；圆点可直接跳转，首尾停止，不自动换组。点击 TD／LD 或按 Tab 切组。
- 悬停画面才出现播放、放大图标；空格切换播放状态。Esc 先退出放大，再关闭演示，返回原主菜单。
- 本轮仍是截图占位，双图页轮播两张图；单图页只示意播放按钮状态，没有实际视频或伪造进度条。此限制在交付说明中明确，不给游戏画面叠加重复的评审水印。
- 开窗约 230 ms，翻页约 150 ms，关闭约 140 ms。翻页只切换内容，不切场景，也不要求从头观看。

正式接入时每页视频建议 8–15 秒，无配音、默认静音循环，不自动翻页。保留游戏当前 BGM，关闭窗口或切页立即停止原视频。按键只由顶层窗口处理，不能穿透到主菜单。

## 页面内容

每页的两行说明使用 `guide` 字段；页面标识、图片和后续录制提纲集中在 [content.json](../../DraculasBox/Prototypes/Showcase/content.json)。

| TD · 关卡工具 | 演示重点 |
|---|---|
| 在游戏里造关卡 | 点涂与矩形、绘制与擦除、一次笔画一次撤销 |
| 改完就能试 | F5 试玩并返回，原稿与视图保持 |
| 求解，再逐步复查 | 求解、播放、前后单步；区分无解和搜索未完成 |
| 先有一份草稿 | 机制选择、预览、采用、撤销替换 |
| 直接编排正式关卡 | 节点排序、上下支线、空格预览、进入编辑 |
| 保存与复用 | 复制正式关卡、独立副本、JSON 导入导出与草稿恢复 |

| LD · 玩法设计 | 演示重点 |
|---|---|
| 吸血鬼的推箱子 | 推箱、躲光、安全入棺；死亡与撤销 |
| 搬动两格阴影 | 太阳影长与推箱站位、安全路线 |
| 光源也能被推动 | 四向射线、遮挡、隔箱推灯 |
| 开门也会放进光 | 承重开门同时改变通路与光路 |
| 给光线转个弯 | 两种固定镜向、灯光反射、机制组合 |

内容依据当前代码与设计基准组织。草稿生成只介绍辅助起稿，不承诺关卡质量；未接入的难度评级、高箱、太阳反射和时段机关不列为现成功能。截图为已有项目记录，不替代最新版本验证；机关页暂用暮夜配色，正式录制统一主题。求解页目前借编辑器静帧占位，确认后按提纲补录实际操作。

## 原型和素材

- Unity 菜单 `Tools → Dracula's Box → Prototypes → 作品演示`：在 Edit Mode 打开独立预览窗口，使用 Canvas、TextMeshPro 和项目已有 UI 图标。显示对象位于临时预览场景，不挂入游戏场景。
- [第二稿画面与动效](../../DraculasBox/Reviews/Showcase-20261111-r2/)：Unity 离屏渲染，动图只展示界面动线，游戏画面仍为静帧。第一稿的独立 Windows 宿主已移入旧评审目录归档，不再作为当前入口。
- [演示素材目录](../../Assets/DraculasBox/Showcase/Editor/)：项目截图及来源索引。确认后再新增正式录屏，当前没有 VideoClip 或游戏运行时引用。

原型的主菜单是游戏截图，只有边缘索引签及演示窗口可操作。预览以现有字体源生成自有临时字库，关闭后回收，不修改项目字库。实际接入仍需约束入口、代码和媒体引用为 Editor 范围；正式包中不显示该入口，也不载入演示媒体。本轮不改游戏场景、运行脚本、存档或正式关卡。
