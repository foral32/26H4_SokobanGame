# Dracula’s Box 项目文档

项目英文名暂定 **Dracula’s Box**，文件与模块标识建议使用 `DraculasBox`。本目录维护基础设计与架构，不展开具体关卡、详细系统策划或验收用例。

| 文档 | 内容 |
|---|---|
| [设计基准](Design/Prototype设计文档.md) | 项目定位、核心机制、视觉方向与工程基线 |
| [技术框架](技术框架.md) | 模块职责、权威状态、基础数据流与复用边界 |
| [决策日志](DECISIONS.md) | 已选定的名称、机制、灯具及动效方向 |
| [版本路线](版本开发文档.md) | 当前阶段与后续工作方向 |

正式原创项目的规则与表现设计以本目录为入口。早期机制研究与造型探索保留在本地 `Investigate`；[Box or Void 学习复刻](../Assets/Studies/BoxOrVoid/) 保持独立。

原创模块已在 `Assets/DraculasBox/` 建立，当前正式目录为四章共二十四个主线、六个可选支线与关卡编辑器，支持同关多盏灯与两种固定朝向的镜子。项目图文介绍、启动与编辑器用法见 [仓库首页](../README.md)，开发状态与体验边界以版本路线为准；本轮未分配功能版本号。
