# 玩家关卡编辑器实施记录

2026-11-07：所有者确认玩家造关界面方向，并授权实现完整闭环及玩家流程迭代。补充要求：撤回支持 Z，高频操作有快捷键和清晰提示。本次不分配新版本号、不提交 Git。

## 已实现

1. 版本化关卡文档、编辑会话、原子历史、完整绘制/选区/裁切；结构检查及输入规则。
2. 独立用户关卡库：原子保存、备份恢复、自动草稿、新建/副本/回收、导入预览与非覆盖导出。
3. 游戏内玩家 UI：场景内固定框架，底部物件栏、查看格子、二层工具、快捷键提示、选关式关卡库。
4. 接入同一 PuzzleSession 试玩，隔离剧情进度，通关回传和原样返回编辑。
5. 玩家文字与键位：主标题「关卡创作」，动作「试玩 / 返回编辑 / 选项」，物件名「灰墙」搭配「单击放置 · 拖动绘制」。大标题用原游戏粗体，正文与提示用工程已有的思源黑体中等字重；图标、标签和键位分层呈现。
6. 图形射线命中与指针事件驱动的实际 Unity/Windows 流程；渲染截图检查、EditMode 数据验证与独立构建。

## 约束

- 保留工程已有无关修改。使用当前共享场景，不新增独立关卡 Scene。
- 固定 UI 由场景对象持有，可在未运行时检查。关卡和缩略图由数据生成。
- 正常输入仅窗口聚焦时读取，文本框聚焦时禁止编辑快捷键；测试隔离真实设备，不接管系统鼠标键盘。
- Z/Ctrl+Z 撤回，Y/Ctrl+Y/Ctrl+Shift+Z 重做；B/V/E/I/L/U/F 对应摆放/查看/擦除/取物件/直线/矩形/填充；M 框选、Shift 追加；1–6 物件，Tab 黑白，Q 视角，G 网格，Home 适配，F5 试玩/返回编辑，Ctrl+S 保存，Esc 分层取消，F1 操作指南。
- 原始研究关卡只读，草稿和剧情进度分开。保存无效草稿合法，游玩前检查；“已玩通”绑定布局哈希与规则版本。

## 玩家流程迭代

- 实际进入主菜单→我的关卡→新建→绘制→试玩推箱通关→返回编辑→保存→重新打开→导出→导入副本；全程调用当前产品的同一规则、输入轮询与 UI 事件路径，临时存档和剧情进度隔离。
- 修正 CanvasRenderer 缺失与 CanvasGroup 假空引用导致的运行异常。
- 修正关卡库标题裁切、稀疏卡片偏置、撤回键位与操作指南重叠、关闭按钮被裁切。
- 调整格子内容面板的高度和分页间距，防止最后一层与按钮挤在一起；层级边界和灰墙不可换色操作置灰。
- 修正连续墙面阴影的绘制顺序，避免后绘制的墙影横穿相邻墙体；连接判断与正式游玩视图保持一致。
- 修正绘制途中按 Z 多撤回上一笔、追加框选中未选中的洞被覆盖、关闭填充预览后残留高亮，以及新关卡继承旧悬停格的问题。
- 保存损坏后再次保存仍保留上一份可用备份；关卡库的改名、复制、导出使用最新自动草稿，避免改名时把未保存布局丢掉。
- 放大画布后，拖动画笔越过可见棋盘或格子面板不再继续落笔；回到画布不会跨过被遮挡的区域补画。

## 玩家反馈后的调整

点击「导入」先打开[游戏内导入面板](../../Evidence/Creator/Windows1920/08-import-guide.png)，说明支持编辑器导出的 JSON 关卡或布局。点击「选择本地文件」才打开 Windows 文件选择器，取消后可继续在面板内操作。也可粘贴文件路径后点「预览关卡」，或从关卡库直接按 Ctrl+V。预览中可重新选择文件，确认加入时才写入关卡库。

新建卡片是空库唯一的可点击新建入口。离开编辑时的小弹窗显示关卡名及三种操作。绘制工具以六张卡片解释手势，每张配格子示意，矩形的边框与实心在选择矩形后出现。选中填充会切换到墙画笔，选中叠箱会切换到箱子。

本轮在两种分辨率各通过 115 项运行流程检查，并检查 [工具面板](../../Evidence/Creator/Windows/19-tool-guide.png)、[离开编辑](../../Evidence/Creator/Windows/18-leave-edit.png) 和 [空关卡库](../../Evidence/Creator/Windows/02-empty-library.png) 实机图。Unity 流程使用受控的系统选择结果和带引号的路径文本。另在独立 Windows 桌面以 Unity Mono 加载交付程序集，实际打开系统文件窗口，验证选取带空格的中文 JSON 文件、选取导出目录和取消操作均返回预期结果。

## 主菜单与编辑面板的实机修订

- [主菜单](../../Evidence/Creator/Windows1920/01-creator-focus.png)：四枚图标按圆面校准，避开右下投影。关卡创作采用专用的[棋盘画笔图形](creator-mark.svg)，随菜单焦点变色；在保存的场景中也可见。
- [操作指南](../../Evidence/Creator/Windows1920/16-shortcuts.png)：F1 打开双页速查表，按绘制、选区、编辑试玩、查看棋盘分组。操作名与键帽对齐，可以直接找“撤回”或“平移”。
- [格子内容](../../Evidence/Creator/Windows1920/11-stack.png)：每行用关卡内的物件缩略图对应层级。绿色条表示当前操作的层，取作画笔、移除、调序均针对这一层；空格只显示空态，[翻到末页](../../Evidence/Creator/Windows1920/17-stack-pages.png)时面板随剩余层数收短。

Windows 包在 [1280×720](../../Evidence/Creator/Windows/flow-report.json) 和 [1920×1080](../../Evidence/Creator/Windows1920/flow-report.json) 下各通过 118 项检查。其中专门核验了保存场景中的创作图标、指南文字有无截断，以及六层格子从四行翻到两行时的面板高度。截图由实际游戏相机以测试窗口的分辨率输出。
