# 玩家造关 UI 修订

2026-11-07 · 根据所有者“面向玩家、符合游戏内 UI 美学”的反馈重做，方向已获批准并接入 Unity。下文保留批准时的设计依据；实际实现与文字迭代见 [实施记录](实施记录.md)。

## 设计判断

上一稿以 TD/LD 的工作效率为界面组织依据，产生了常驻工具栏、属性栏、状态栏和检查抽屉。完整的工具能力需要保留，但进入产品的玩家应该先理解“摆东西、改一改、玩一下”。本稿以玩家创作一关的过程组织操作。

沿用原作可辨认的 UI 语言：深灰空场、略带厚度的方块、圆形菜单按钮、粗体中文、绿色四角选框、蓝色目标标记和圆形闭合转场。减少矩形表单、分隔线、表格状态和常驻参数。

视觉值：背景 `#3A3D3E`，阴影 `#252728`，正文 `#ECEEEC`，次要提示 `#BAC2C6`，选框 `#76BD38`，蓝色点缀 `#769CDB`。绿色表示“当前选中/可确认”，不拿它装饰整页。标题用工程现有黑体，按钮与棋子均来自当前复刻资源。

## 主画面

- 棋盘占据画面中央，直接呈现游戏里的墙、箱子、角色和目标。网格默认弱化；坐标仅在需要精确操作时显示。
- 左上为返回、关卡名称；右上“玩一下”是最突出的按钮。保存、改名、棋盘大小和分享放在有文字标识的“更多”菜单。
- 底部是物件栏：白/黑切换、墙、箱子、角色、两种目标、灰墙。点选后对象进入指针预览，点击放下，按住可连续摆放。
- 选择、摆放、擦除是少量圆形快捷工具。直线、矩形、填充、吸管、框选/复制/变换在“更多工具”中按任务分组。功能保留，复杂度逐层展开。
- 撤销/重做随时可见。控制提示根据当前拿起的对象变化，不常驻整排键位说明。

## 叠层要在棋盘上讲清楚

用“查看”点到一格，临近棋盘浮出“这一格里”小窗：把箱子和角色逐个摆开，明确标注“上面”“下面”。选择被覆盖的白角色后，可“拿走”或“放到上面”。底墙和目标仍单独显示，不能被误当作可移动物体排序。

浮窗只在玩家主动查看时出现；它不占据固定侧栏。先检测剩余空间，优先放到棋盘旁，必要时轻移棋盘，不遮住选中格、主工具或“玩一下”。Esc/点关闭收起；保留当前画布位置。

## 从问题回到动作

点击“玩一下”时才检查基本条件。缺白角色时显示该角色的大图和“还少一个白色角色”，主按钮为“去放一个”：关闭提示并直接拿起白角色。灰墙占位则高亮出问题的格子并提供“去看看”。不会用“结构校验失败”“对象枚举”等术语要求玩家理解实现。

被覆盖玩家是本作允许的机制，不作为阻止游玩的错误；查看格子时直观呈现即可。基本条件满足后直接圆形转场进入试玩；“已玩通”必须对应当前布局的实际通关记录。

## 我的关卡与试玩

“我的关卡”沿用原作选关体验：方块缩略图、绿色角标、名称和少量状态、左右选择。选中一关后提供“继续制作”；新建使用同排的“做一关”空白方块。导入、分享、复制、回收等通过第二层菜单进入，关卡多时补分页/查找，不常驻文件管理表格。

试玩时收起制作工具，保留原游戏的移动/切换/撤回/重置提示和明确的“继续制作”。返回后恢复棋盘视角、选格与编辑历史。网页稿只演示界面切换，正式版继续使用同一 Unity 规则核心。

## 易用性与验收

- 每个图标有可读文字；鼠标指向和键盘聚焦都显示反馈。主要动作的按钮视觉大小不小于 44 个参考像素，小型参数控件在 Unity 实现时补足点击热区。
- 圆形转场只用于整页与制作/试玩切换；选物、摆放、擦除、撤销不被长动画阻断。
- 1280×720 与 1920×1080 保持一致的棋盘和控件比例，不依靠页面滚动才能操作主界面。
- 新玩家不看说明书即可完成：拿起箱子→放置→撤销；查看被盖住的角色→移除→获得可操作的问题提示→恢复。
- 在试玩前后的视觉变化中，玩家能够明确知道自己是在制作还是游玩，且不会丢失编辑结果。
- 仍保留上一稿的版本化数据、原子撤销、草稿保存/恢复、裁切确认、导入导出和同一玩法核心等技术要求。
