# 动效拆解：阅读与实现依据

工作台入口：`http://127.0.0.1:4177/#motion`。选择一组效果，点关键时刻或逐帧；属性曲线可定位当前源码。播放默认慢放，未自动播放。参数实验只影响网页。

## 当前工程的主要通道

|通道|驱动数据|默认参数|关键源码|
|---|---|---|---|
|位移|Before / After 的格子位置|100ms 线性插值|BoardView.RefreshPieces|
|角色挤压|归一化 t 的半个正弦波|移动 ±20%；受阻 ±6%|BoardView.RefreshPieces|
|被覆盖反馈|下层角色标记的横移|100ms 两次往返，幅度 0.04 格|BoardView.RefreshPieces|
|下层 / 完成标记|被移动或改层序的格子|到位后 300ms，α 0→1，尺寸 0.65→1|MarkerAmount / SetMarkerAmount|
|切色背景|保留旧底图，叠加新底图|100ms 交叉渐变|StudyBackdrop.SetTone / Update|
|菜单跟随|当前位置与目标位置|blend=1−exp(−Δt/0.065)|StudyMenu.LateUpdate|
|选中 / 按下|目标缩放值|选中 1.045；按下 0.94，保持 100ms|StudyMenu.LateUpdate|
|面板入场|自打开起的时间|140ms；透明度线性，缩放 0.98→1 用 EaseOutCubic|StudyMenu.OpenPanel / LateUpdate|
|圆形转场|Closing / Covered / Opening 状态机|闭合与打开各 300ms，中间至少遮住一帧|StudyTransition.Update|
|圆孔几何|画布半对角线 × Aperture|192 段；普通圆环 579 顶点 / 768 三角形|StudyIrisGraphic.OnPopulateMesh|
|过关消散|固定的格子哈希门限|0.3s 开始，0.9s 消散结束，1s 发起返回选关|PuzzleApp.Update / BoardView.Update|
|背景描边粒子|位置、相位、缩放、透明度|15 个；匀速漂移，正弦呼吸，越界到对侧|StudyBackdrop.Update|

位置、缩放、透明度使用独立属性通道。`Time.unscaledDeltaTime` 推进局部时间，因此不依赖 timeScale；逻辑状态在 Present 前已经算完，Transform 插值不参与推箱判定。

菜单示例使用章节卡片；标题按钮的缩放对象是背景 panel 引用，独立图标不随该引用自动缩放。指数平滑在相同时间达到相同进度，30 / 60 / 120Hz 的每帧 blend 不同。

过关的最终移动占前 100ms，完成勾接着渐显到约 400ms；消散从 300ms 开始，两者有重叠。音效冷却 40ms 是最小间隔，实际由 Update 的帧时刻触发，60Hz 示例约每 50ms 一次。

## 演示与工程的边界

- `scripts/motion_sources.py` 从当前 C# 与场景序列化值读取参数，并记录源码散列。代码标记改变时，准备步骤会报错，避免静默使用旧值。
- 网页复用关卡 JSON、贴图与规则快照，重建对应公式；并未连接 Unity 实时调试器。局部放大、轨迹、禁用挤压和参数旋钮是学习工具。
- 粒子采用固定教学初相位与尺寸，便于重播和比较；漂移、越界、缩放、透明度公式来自工程。未宣称与 Unity 随机种子生成的每个粒子逐帧一致。
- 网页圆孔用 SVG 掩模显示等价孔径，并额外绘制 Unity 的圆环分段；Unity 实际通过 UGUI 顶点与三角形生成网格。
- `Unity 实机` 使用已有归档，独立于交互时间轴播放。转场片段为 `Evidence/Presentation/Transitions.mp4`，不是新录制的原作视频。

## 文件与验证

- `src/motion-model.js`：位置、正弦、指数平滑、孔径、消散、粒子的计算。
- `src/motion-content.js`：16 个案例、实际关卡快照、曲线、关键时刻与源码位置。
- `src/MotionPreview.jsx`：Sprite 投影、菜单卡片、圆孔和网格预览。
- `src/MotionExplorer.jsx`：播放、逐帧、采样率、曲线选择与实验参数。
- `npm test`：保留 21 关规则回放，增加动效边界、帧率独立性、覆盖帧、圆孔拓扑、音效冷却与源码一致性检查。
- `npm run test:motion-browser`：通过真实 Chrome 操作 16 个效果，验证慢放、暂停、逐帧、属性渲染、参数恢复、源码、视频及窄屏。
- `npm run test:browser`：保留原有工作台交互回归。

不修改 Unity 资产、场景或动画实现，不以网页的公式检查替代 Unity 的真实运行验收。
