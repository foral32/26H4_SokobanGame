# 程序与墙块贴图拆解改进

目标：从 Unity 的运行入口出发，看清组件何时创建、关卡数据怎样变成局面、一次输入如何计算并呈现结果；通过操作邻格理解墙块 mask。

范围：只改本地研究工作台，不修改 Unity 玩法、场景、素材或其他工作中的文档。内容以当前源码为依据，明确区分复刻结构与原作取证。延续既有视觉设计。

实施清单：

- [x] 加入实际启动链、生命周期、对象创建顺序与源码摘录。
- [x] 在同一规则解释器中记录递归判断、移动计划及提交步骤，展示真实关卡案例。
- [x] 加入可操作的历史与重置检查点，说明静态定义和动态状态。
- [x] 加入组件关系、类型、输入输出与定位源码。
- [x] 用共享的墙块计算函数连接 3×3 邻格、四位编码、16 张贴图与凹角补片。
- [x] 对齐 21 关回放，并验证递归失败不改变位置、撤销恢复层序和 mask 全组合。
- [x] 构建后在桌面与窄屏验证交互、源码定位、无溢出和 Console。

交互验收：可从“点下运行”沿节点定位到 `PuzzleApp.Start → EnterPuzzle → Update → Act`；单步执行时棋盘、调用栈、移动计划、变量与源码相互对应；点击上、右邻格能从 `0011 = 3` 变为相应贴图；四向相连但对角缺失时仍是 `mask=0`，用独立角片补足。

验证使用本机 Chrome / Playwright；当前未提供 Browser 插件及 browser skill。网页演示不是连接 Unity 的实时调试器，也不替代真实键鼠验收。

验证结果：32 项逻辑与源码检查、69 项 Chrome 交互检查通过；生产构建通过。检查覆盖 1440×1000、390×844、320×844，包含状态变化、源码摘录、窄屏无整页横向溢出和 Console 无错误。
