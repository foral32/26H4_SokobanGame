# 第三、四章关卡试作

每章四关，保存到玩家实际的“我的关卡”。没有替换正式主线，也没有新增规则；关内不写解法提示。

| 名称 | 核心关系 |
| --- | --- |
| 试作 3-01 · 合门 | 一块板同时开通行门和光闸；人离板进门，光闸先关。 |
| 试作 3-02 · 留灯 | 灯有重量，也会发光；用箱子把它留在压板上。 |
| 试作 3-03 · 交棒 | 一只箱子通过第一道门，继续参与第二块板的重物交接。 |
| 试作 3-04 · 接班 | 原来压板的箱子借去搬灯，另一只箱子回填空出的板。 |
| 试作 4-01 · 绕光 | 反射光截断近路，先处理上方的箱子，从镜背接近。 |
| 试作 4-02 · 连折 | 两面镜子连续转光，反光出口随镜子队列移动。 |
| 试作 4-03 · 交照 | 两盏灯封住不同操作面，借箱子同时搬灯、搬镜。 |
| 试作 4-04 · 归镜 | 镜子先离板参与改光，再回到板上开门。 |

3-01、4-01 是短谜题；每组最后一关包含更多搬运和回收。难度与趣味仍以实际试玩反馈为准，不能由最短步数直接推断。

## 第三章

**合门。** 两门初始均闭。A 先横移，挡住照着压板的竖光；人踩板后，两门一起开。离板踏入上门时，人占着的门保留通路，另一扇门关闭并挡住横光。再推开右室门后的 B，走过原本危险的横光区。禁止“离板而占门保开”或禁止光闸关闭时均无解。不是用初始占门状态冒充验证。

**留灯。** B 从上方把灯送到下排，A 再从侧面护送它去远端压板。灯留在板上维持出口门，同时 A 留在其出光方向上保护回程。禁止灯进入压板时无解，不能简单用任一只箱子替代灯压板。删去了原稿中不影响路线的上方门，并封成墙。

**交棒。** B 经第一块板、第一道门进入右室，从上方推动 A 压住第二块板；随后继续下推，B 接替 A 压板，A 则把灯推出照着下门的那一排。开门、保压和卸光发生在同一串实体的连续移动中。两组板、离板回收及连推分别做了必要性检查。

**接班。** B 起初压着板，但棺材通路仍受光。先将 B 移出板，带去把上方灯横移一格；再绕到 A 另一侧，把 A 运回板上，重新打开出口。要管理的是两只箱子的先后职责。原稿中多余的上门也已移除。此关的回程最长，审核时重点看返程是否拖沓。

## 第四章

**绕光。** 镜子把横光折为竖光，中央近路不可穿过。把上方挡路箱移开，从外侧绕到镜背，再横推镜子，腾出棺材前的入口。把镜子改为普通箱子的对照解少四步，反射光确实改变了人的路线。

**连折。** 先把另一面镜子送到下排，再从左推动双镜队列。两次连续反射会将照亮的列换到别处；必须把实际镜位和出光口一起看。实际 Core 已验证双镜都必须移动、必须连推；回放中确有同一条射线经过两面镜子，未用“同时亮着两面镜子”代替连续反射。

**交照。** 用 A 隔推可动灯 K，接着把前面的镜子也带走。固定灯 L 不增加最短解长度，但它封住了中途从上侧绕回镜前、逆向推列车的路线。删除 L 后的一条19步逆向解，在原图会受光死亡；已用真实 Core 对照回放。最后的镜子同时接收两向入光，出口方向也要纳入站位判断。

**归镜。** 镜子起初压板；先离板，将反光导向墙边，借出接近 A 的路线。A 隔推灯后，玩家绕回，把镜子送回原板，打开棺材前的门。镜子与箱子都要参与改光与站位。原稿中无实际作用的上门已删去，保留出口门。
