### 在 Unity Play Mode 制作正式关卡

在 Unity 编辑器的 Play 模式，从主菜单右下角「编辑正式关卡」进入。选择章节后，单击关卡格即可编辑棋盘。返回时会定位到刚编辑的关卡。正式包主菜单保留四个玩家入口。

| 制作需求 | 操作与结果 |
| --- | --- |
| 新建或改棋盘 | 点「新关卡」直接进入新棋盘，也可右击已有节点，在「关卡操作」里复制。点击顶部名称输入框改名，Esc 结束输入并保留修改。按住中键拖拽画布，点击底部缩放百分比可回正。 |
| 调整主线和支线 | 拖入横排间隙可以插入或调序。拖到某个主线格上方或下方可挂支线，两侧都由该关解锁，同侧支线可并排。移动主线时支线随行。要把带支线的主线降为支线，先给它的支线另选解锁关。Esc 取消拖动，Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做。 |
| 跨章编排 | 章节卡片旁的「…」可直接改名、前移、后移或删除章节；新建后也在此命名。章内的「章节…」打开同一小面板。删除须确认，写回前可在章节页撤销或重做，至少保留一个章节。关卡节点单击直接编辑；「…」或右键菜单可复制、移至章节或删除，移动主线时支线随行。 |
| 试玩、保留半成品 | 「保存草稿」和编排修改写到本工程的 `Library/DraculasBoxCampaign`，下次进入 Play 可接着做。F5 往返棋盘和试玩。试玩通关会记录路线，玩家进度独立。 |
| 发布正式内容 | 章节页或关卡图右下角的「写回工程」打开变更弹窗；逐项勾选章节、关卡编排、名称、棋盘或路线修改。校验失败时显示具体原因，可先写回其他有效条目，未选内容保留为草稿。有效路线的推数自动校正；新关卡或布局／路线变化的关卡需有有效路线。确认后更新正式数据与构建引用；移出目录不会删除此前写入工程的棋盘文件。 |

改名、调序和跨章移动保留关卡 ID，已有通关记录仍有效。编排撤销和重做覆盖当前制作会话。发布前若检测到工程源文件被其他工具改动，会保留工作稿并提示处理。正式内容的写入工具仅在 Unity Editor 中注册。

| 游玩操作 | 按键 |
|---|---|
| 走动、推动 / 菜单选择 | 方向键或 WASD |
| 菜单确认 | Enter / 空格，也可鼠标点击 |
| 撤销 / 重置 | Z（可长按） / R；重置也可撤销 |
| 暂停 / 返回 | Esc |

编辑器中，A 选择、Q 绘制、E 擦除；P 切换点选／点涂，R 切换框选／矩形，数字键选择画笔，[ 与 ] 选择两种斜镜。选择模式可点选或框选地形与物件，拖动预览后松手提交，Delete 删除，Esc 取消；左键绘制，右键临时擦除，Alt+左键取色。滚轮缩放，中键拖动画布；Z / Y 撤销和重做，Ctrl+S 保存，F5 试玩或返回原稿。素材栏可滚动和收起；“场景”可输入 3–32 格尺寸并配置阳光方向。一次拖动对应一条撤销记录；试玩保留原稿、编辑历史与视图，不计入主线进度。

选择、绘制、擦除是三种操作；选择模式用点选／框选移动或删除图层内容，绘制与擦除模式用点涂／矩形修改区域。Shift 可临时启用矩形；矩形放置或擦除会保留地板，拖动中只预览，松开后整体应用并占一次撤销，Esc 取消。右键可临时擦除。吸血鬼和棺材为单点物件，箱子、灯与机关支持区域放置；不可放置格和超出数量上限的部分保持原样。左下数字为机关连接组，仅在选择压力板或自动门时显示；同组压力板控制同组门。

关卡库显示使用实际美术的布局缩略图。单击选择，双击或 Enter 编辑；三列预览下方的编辑与“...”绑定选中的关卡，更多菜单提供复制、导出和移除；悬停不会改变操作对象。移除记录重新打开后仍可恢复，冲突时保留两个版本，不覆盖已有文件。导入先显示格式说明，再由玩家选择文件、预览并确认；确认时生成独立关卡，不覆盖来源文件。无法读取的文件保留，可查看文件名与原因。

保存后的内容为未保存标记的基准，撤销回到该内容会清除标记；保存失败会保留原文件及当前草稿。已保存的内容不重复显示恢复入口，明确放弃的草稿也不会重新出现。草稿恢复损坏时尝试上一份完整记录。未放置角色或棺材的草稿可保存、导入后继续修复；重叠、越界等无效数据在进入预览前拒绝，试玩还要求安全出生点。

## 本轮内容

第一章「光与影」：箱子、阳光、接力、并肩、照射、归途。依次引入推动、太阳箱影与四向灯。

第二章「阳灯」：借过、窗边、交叉、换手、错层、回身。保留此前精简，补入同时遮住两条光路、错开灯位再换侧。支线「借道」在主线 4 后解锁，「回借」在主线 6 后解锁，要求回收遮挡物并重新安排灯位。移出的旧重复变体归档在 `Content/Retired/`。

第三章「通行」：留住门、换岗、合上光、门缝、两边照应、归还。短的替代承重教学提前到第二关，再探索关门遮光、门内挡光和箱灯回用。支线「接手」在主线 2 后解锁，「接力」在主线 6 后解锁，组合角色接替承重、跨区运箱和多组门的往返规划。

第四章「镜面」：转光、借墙、背面、两束光、换位、回照；主线 3 解锁支线「对照」，主线 6 解锁支线「往返」。先用单镜改变危险光柱，再进入连续反射、两盏灯的换位和镜子承重；进阶关的错误走法包含反射回玩家身上的光。

压力板由角色、箱子、灯或镜子持续压住，同组任意板触发开门。门关闭时挡路、挡光；门格有角色或物体时等待清空再关。机关和光照在每步提交后一起更新，开门放进光也可能致死；撤销完整恢复。连接组用颜色和点数对应。编辑器新增 9 / 0 压力板与自动门画笔，下方 1–4 按钮选择连接组，预览、保存、导入和试玩共用同一套规则。

太阳按关卡参数照射；普通箱和首版同高墙体在背光侧投两格影。四向灯可推动，仅照亮上下左右未被墙、箱子、另一盏灯或关闭的门挡住的格子，距离暂无限；它不会照亮斜向格。同关可有多盏灯；被任意一束光照到的普通地板都危险，挡住一盏不代表该格安全。夜晚只关闭太阳。角色可走进光内，随后灼烧、散灰并提示「Z 撤销」。撤销恢复角色及本步推动的所有物体。棺材格遵循同一光照规则：未受光时入棺通关，受光时走入会死亡。

编辑器可连续放置多盏灯，各自保留位置与光晕，导入、导出和试玩一致。两种斜镜分别用 [ / ] 选取，也可在材料列表中选择；镜向固定、两面反射四向灯光、可连续反射，沿用正常走推与撤销。第四章为夜间关卡，镜子在日照编辑预览中按普通同高实体投影，尚未扩展太阳反射。没有高箱和时段切换机关。行走使用短位移与挤压回弹，披风跟随，入棺使用缩小下沉与棺盖滑合。

输入缓冲保留移动中短按的下一步，长按起步延迟与后续重复分开；撤销、重置和离开页面清空待执行方向。光影随实体位移过渡，受光地板保留材质与格线，用柔光和光轴显示照明，封闭边界保留日照方向箭头。

菜单采用深色背景、立体字标、几何图标和带倒角的关卡块，只保留必要名称、按钮与错误提示。支线位于对应主线下方，锁定、解锁及完成后均保留红色外框；右上角只统计主线。入棺、棺盖闭合后直接圆形转场到下一主线关；章末顺接已解锁的下一章，全部主线完成后返回章节选择。支线通关回本章选关，试玩通关直接回编辑原稿。

## 数据与代码

关卡数据在 `Assets/DraculasBox/Content/Levels/`；章节和节点依赖在 `Chapters.json`。自制关卡位于 `Application.persistentDataPath/DraculasBox/UserLevels/`，进度与音量在同级 `progress.json`，恢复草稿为 `draft-recovery.json`；导出与回收分别在同级 `Exports/`、`Trash/`。自动化回放使用临时存档目录。

`Core` 保存纯 C# 规则、完整状态历史和编辑文档；`Runtime` 负责场景编排、显示、输入、UI 与玩家编辑器；`Editor` 提供场景准备、后台回放和 Windows 构建菜单。结构约定见 [技术框架](../Document/技术框架.md)。原复刻代码与存档保持独立；字体和音效复用工程已有资源，BGM 使用独立选定的两首作品，复制的几何精灵保存在本模块中。
