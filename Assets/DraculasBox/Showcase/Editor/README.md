# 作品演示素材

`ReferenceStills/` 保存界面交互原型使用的项目截图，来源见同目录 `sources.json`。全部为静帧占位，不是新录制的视频，也不作为当前项目的重新验收证据。

页面内容位于 `DraculasBox/Prototypes/Showcase/`。第二稿使用独立的 Unity 原生预览窗口，入口为 `Tools → Dracula's Box → Prototypes → 作品演示`；不启动游戏、不访问游戏存档。评审稿位于 `DraculasBox/Reviews/Showcase-20261111-r2/`。

后续确认演示方案后，再在本目录增加 `Recordings/`，按 `td01`、`ld01` 等页面标识归档视频。当前不创建空视频、占位 VideoClip 或运行时引用。

素材放在 Editor 目录下，后续接入仍须明确限制为 Unity 编辑器中的 Play，不能依赖单纯隐藏按钮来隔离正式包。
