# 业务代码文档

## 核心模块
### Tools/
- Framework/：基础框架类
- Manager/：管理器类（Timer, Particle, PostProcess等）
- Gameplay/：游戏逻辑组件
- UI/：界面相关工具

### Utils/
- GToolkit.cs：通用工具函数
- ExpandedClass.cs：扩展方法
- CurvesLibrary.cs：动画曲线预设

## 代码规范
- 命名约定：PascalCase类名，camelCase方法名
- 注释：中文注释，说明功能与参数
- 错误处理：使用try-catch，记录日志

## 测试策略
- 单元测试：关键逻辑函数
- 集成测试：模块间交互
- 性能测试：对象池效率，GC分配

## 维护指南
- 定期重构重复代码
- 更新依赖版本
- 文档同步更新
