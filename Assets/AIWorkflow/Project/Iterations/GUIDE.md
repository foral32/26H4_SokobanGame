# Iterations — 迭代记录指南

## 命名规范

`Iter_MMDD_[简短描述].md`

示例：`Iter_0318_核心移动系统.md` / `Iter_0325_战斗原型.md`

## 何时创建

每完成一个里程碑或阶段性目标时创建一条记录，不是每改动一次。

## 内容模板

```markdown
# Iter_MMDD_[描述]

## 目标

## 完成内容

## 可玩性感受
（这次改动玩起来怎么样？手感/体验变化）

## 遇到的问题

## 下一步

## 值得记录的经验（可选）
（有复用价值的发现 → 同步写入 Memory/knowledge.md）
```

## 完成后

- 有价值的经验写入 `Memory/knowledge.md`
- 更新 `Memory/ProjectSnapshot.md` 的开发阶段和近期决策
